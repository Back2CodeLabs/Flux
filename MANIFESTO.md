# Project F.L.U.X. Manifesto

Nous ne construisons pas un chatbot.

Nous construisons une équipe.

Chaque agent possède une mission.

Chaque mission possède un objectif.

Chaque objectif sert son utilisateur.

Nous privilégions :

- les standards ouverts
- les logiciels Open Source
- les architectures simples
- les composants légers
- les services indépendants

Nous refusons :

- la complexité inutile
- les dépendances propriétaires
- les architectures surdimensionnées
- les fonctionnalités sans valeur

Nous croyons qu'une petite équipe d'agents spécialisés est plus efficace qu'un agent universel.

Nous suivons les Five Stars.

Smart.

Small.

Simple.

Secure.

Standalone.

Mission First.

Everything else is implementation details.
