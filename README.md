# 🚀 Project F.L.U.X.

> **Federated Learning & Universal eXecution**

**Project F.L.U.X.** est une plateforme d'agents IA autonomes, auto-hébergée, modulaire et 100 % Open Source.

Sa mission est de permettre à une équipe d'agents spécialisés de collaborer pour assister un utilisateur dans ses tâches personnelles, professionnelles et techniques.

---

# Philosophy

Project F.L.U.X. repose sur les **Five Stars**.

⭐ Smart

Créer uniquement des fonctionnalités qui apportent une réelle valeur.

⭐ Small

Optimiser chaque composant afin qu'il puisse fonctionner sur un matériel modeste.

Notre matériel de référence est un **Dell Optiplex 5080 Micro**.

⭐ Simple

Toujours choisir la solution la plus simple répondant au besoin.

⭐ Secure

La sécurité est intégrée dès la conception.

⭐ Standalone

Chaque composant doit pouvoir fonctionner indépendamment.
