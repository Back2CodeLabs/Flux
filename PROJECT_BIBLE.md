# Purpose

Le Project Bible est la source de vérité du projet.

Toute décision technique, fonctionnelle ou architecturale doit respecter ce document.

En cas de conflit entre plusieurs documents, le Project Bible fait foi.

---

# Vision

Créer une plateforme d'agents IA autonomes, auto-hébergée, modulaire et open source capable d'assister son utilisateur dans tous les aspects de son quotidien.

Le projet doit fonctionner sur un matériel accessible.

La machine de référence est :

Dell Optiplex 5080 Micro.

---

# Mission

Créer non pas une IA.

Créer une équipe.

Chaque agent possède :

- une mission
- des compétences
- une mémoire
- des outils
- des limites
- une personnalité

---

# Five Stars

## ⭐ Smart

Chaque fonctionnalité doit apporter une valeur réelle.

---

## ⭐ Small

Chaque composant doit être léger.

---

## ⭐ Simple

Toujours privilégier la solution la plus simple.

---

## ⭐ Secure

La sécurité est intégrée dès la conception.

---

## ⭐ Standalone

Chaque agent peut vivre indépendamment.

---

# Core Principles

Mission First

Human First

Open Source First

Docker First

Local AI First

API First

Documentation First

Security by Design

Observability by Default

Automation when Valuable

---

# Success Criteria

Le projet doit pouvoir être installé sur une seule machine.

Le projet doit pouvoir fonctionner sans Internet.

Le projet doit être entièrement documenté.

Chaque composant doit pouvoir être remplacé.

Aucun composant ne doit être indispensable.

---

# Definition of Done

Une fonctionnalité est terminée uniquement si :

✓ le code est propre

✓ les tests passent

✓ la documentation est écrite

✓ la sécurité est validée

✓ Docker fonctionne

✓ les performances sont acceptables

✓ les Five Stars sont respectées

# Agent Philosophy

Les agents ne sont pas des bots.

Les agents sont des spécialistes.

Ils collaborent.

Ils ne se remplacent pas.

Ils se complètent.

---

# Never

Ne jamais ajouter de complexité sans justification.

Ne jamais utiliser une technologie simplement parce qu'elle est à la mode.

Ne jamais sacrifier la simplicité.

Ne jamais compromettre la sécurité.

Ne jamais casser l'indépendance des agents.

---

# Golden Rule

Une bonne architecture est une architecture que l'on comprend encore dans cinq ans.
