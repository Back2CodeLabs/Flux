# Security Policy

Security is part of the architecture.

Never an afterthought.

---

## Core Rules

- Never commit secrets.
- Never expose credentials.
- Always use HTTPS.
- Use least privilege.
- Scan dependencies.
- Scan Docker images.
- Validate backups.
- Test restores.

---

## Security Agents

Guardian is responsible for:

- CVE monitoring
- Secret detection
- Dependency analysis
- Backup verification
- Infrastructure audit

---

## Responsible Disclosure

Please report vulnerabilities privately.

Never publish an exploit before a fix exists.
